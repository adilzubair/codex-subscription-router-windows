# Changelog

## 0.2.0 - 2026-08-20

- Add persistent manual subscription selection for new chats.
- Add an Automatic routing option and account selectors to the native profile menu.
- Add an Active subscription selector to the standalone manager.
- Preserve existing thread ownership when the routing preference changes.
- Fall back to automatic routing when the selected subscription is unavailable or depleted.
- Invalidate cached native runtimes when the injected menu or patcher changes.

## 0.1.0 - 2026-08-17

- Initial source-only Windows release with one-click install and update.
